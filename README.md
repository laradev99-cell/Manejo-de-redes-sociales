# Naimid.Agency

Sitio de Naimid.Agency hecho con Astro.

| Página | Ruta |
|---|---|
| Inicio | `/` |
| Propuesta de manejo de redes | `/manejo-de-redes` |
| Páginas web | `/webs` |
| El vendedor que nunca duerme | `/vendedor` |

Los precios viven en `src/data/precios.js`: se cambian ahí y se actualizan en todas las páginas.

Build: `npm install && npm run build` (salida en `dist/`).
